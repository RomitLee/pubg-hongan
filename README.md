## Babylon.js 迁移版（2026-11-05）

战场使用本地托管的 Babylon.js 9.33.3 渲染：透视镜头、独立三维墙体/屋顶、地面、子弹和技能预警。飞机与降落过程共用三维坐标和相机；鼠标通过射线映射至人物胸部高度平面进行瞄准。保留原有二维游戏规则及墙体碰撞、英雄技能、搜刮、背包和缩圈。

当前是混合方案：人物、树木、载具和空中单位使用现有图片或序列帧的场景平面，尚未替换为骨骼动画三维模型；建筑为基础立体结构，地形没有山体高度。并非完整三维重制。Babylon.js 许可见 vendor/，不依赖外部 CDN。需要支持 WebGL 的电脑浏览器。

引擎集成文件为 babylon-world.js；旧 Canvas 渲染保留供回退开发使用。所有模块直接由 index.html 引入，无需构建。

# pubg海克斯大乱斗

直接用电脑浏览器打开 index.html 即可，无需安装依赖、无需联网。字体在离线时使用系统字体。

## 操作

- 开局运输机横穿地图，空格跳伞；60秒未操作会自动跳伞。
- 跳伞后14秒落地，WASD / 方向键控制空中漂移。落地空手，无初始弹药和药品。空中不计缩圈时间、敌人不会攻击。
- WASD / 方向键：移动；鼠标瞄准、左键开火。
- 靠近自动拾取弹药和药品；武器栏有空位时自动装备地上枪械，最多两把。地图新枪默认自带20发子弹；丢弃的枪保留实际余弹。为适配本作规则，手枪、霰弹枪和栓动狙击枪弹匣容量最低为20发。备用弹药需要搜集，按R换弹。
- 两个武器栏已满时，按E打开背包，点击附近新枪的“替换手持枪”；旧枪连同弹匣余弹留在脚下，可手动拾回。
- E：开关背包；Tab：切换全部地图。鼠标点击“丢弃”可丢下指定武器、整组弹药、药品或护甲；点击附近物品的“拾取 / 装备”可手动拿取。打开背包期间角色停止移动与开火，战斗和毒圈继续运行。
- 靠近敌人箱子后按E，在背包右栏逐项查看和拾取其实际武器、剩余弹药、药品、头盔和防弹衣。房屋从下方门口进入，进入后屋顶隐藏。
- 屏幕底部中央显示两个武器框及弹匣/备用弹药；左下角显示生命、护甲和药品数量；E打开背包查看、丢弃和拾取物品。
- R：换弹；1 / 2：切换武器；Q：治疗；Tab：全部地图；Esc：暂停。
- 半自动武器每次点击开火，全自动武器可按住射击。
- 药品使用期间移动或受到攻击会打断。能量药品提供持续恢复。
- 清除 10 名敌人获胜，可前往下一张地图；毒圈每 70 秒进入新阶段。

## 护甲与地图

- 加入1、2、3级头盔和防弹衣。未装备时会自动拾取，有装备时自动选用更高级或同级耐久更高的装备；也可在背包手动更换。
- 三个等级减伤30%、40%、55%，吸收伤害会损耗耐久。头盔防护头部命中，防弹衣防护身体命中，毒圈绕过护甲。当前采用简化的头部命中概率。
- 敌人使用其携带的枪械射击、消耗弹药，死亡箱保留当时的弹匣、备用弹药、药品和护甲剩余耐久；箱子不会一键全部清空。
- 地图改为海岸岛屿、河道、双桥、海滨小镇、学校教学楼/宿舍/操场、加油站、森林、农场、集装箱港口和机场（机库、跑道、停机坪与塔台）。三张地图沿用此分区结构，分别使用海岛、沙地和雪地配色。
- 海水与河道不可直接穿越，沿两座桥通行；森林树干及集装箱具有碰撞，可作掩体。小地图标出主要地标、河道和桥。

## 本次战斗与场景更新

- 空手左键挥拳，近距离扇形命中，墙体会阻挡；Shift按住潜行，降低移动速度和敌人发现距离。
- 敌人采用前方视野、墙体遮挡和3秒最后位置记忆。枪声和载具噪声会吸引附近敌人，屋外敌人只有靠近门口且视线畅通时才可能发现屋内玩家。
- 被子弹击中时出现红色屏幕边缘、短暂红色闪烁和来袭方向箭头；毒圈持续伤害单独显示。
- F驾驶/离开附近的汽车、摩托车和游艇，方向键或WASD驾驶；汽车在森林东侧道路、摩托车在加油站西侧，游艇在河道中段。游艇只能在河道航行，桥墩阻挡通航，靠岸后F下船。
- 采用倾斜俯视投影、直立人物轮廓和具有高度的墙体，属于Canvas绘制的2.5D视觉，并非3D模型。
- 住宅分为两室一厅、三室一厅；学校有教室，仓库/机场有作业区和大厅，带房门、家具和地面分区。
- combat-world.js：潜行AI、近战、载具、室内布局及受伤反馈。

## 装备栏、烟雾弹与自动搜箱

- E打开背包，左侧显示已穿戴的头盔、防弹衣及耐久，可点击卸下并丢弃；战斗HUD也显示装备图形。
- 背包中点击“设为Q道具”，关闭背包后按Q使用。烟雾弹投向鼠标方向，遇墙停止；约1.7秒完全展开，18秒后消散。烟雾内敌人无法发现玩家，烟雾也遮断敌人视线，但不会阻挡子弹或毒圈伤害。房屋和敌人箱子可获得烟雾弹。
- 下方两个武器槽显示枪械轮廓、名称、弹匣与备用弹药。
- 靠近死亡箱自动收集弹药、药品、烟雾弹及更好的护甲；空武器栏自动装枪。两栏已满时箱内新枪保留，按E手动点击替换，旧枪掉在脚下。打开背包或驾驶时暂停自动拾取。

## 格子背包与倾斜场景

背包物品改为图标格子，鼠标悬停或键盘聚焦显示物品详情，包括枪械伤害/弹匣/换弹、弹药适用枪械、药品效果和护甲耐久；格内保留丢弃、拾取和Q道具选择。

场景采用45度俯视的正交投影比例（纵向缩放约0.707），配合房屋立面、门窗、双坡屋顶、树干与分层树冠，形成2.5D高度。人物、房屋和树木按地面纵坐标排序遮挡；进入房屋时隐藏屋顶，靠近正门或树冠遮挡玩家时淡化。碰撞仍按地面平面计算，鼠标瞄准按投影反算。

## 大厅与加载流程

首页六张角色卡展示人物介绍、被动天赋、主动技能说明和实际CD。仅海岛可选，沙漠与雪地展示“地图正在开发中”，点击不会切换。单机模式进入战场；四人联机模式仅提示“联机模式开发中”。胜利后再来一局也保持海岛。

首页只读取大厅所需图片；点击单机后才请求战斗图集。进入单机前，加载页等待10组实际战斗资源全部读取和解码，随后生成地图与100敌人，进度到100%才进入运输机。进度按已完成资源组计算，不是网络字节百分比。读取或解码失败会阻止开局，并提供重试/返回大厅；后续开局复用浏览器缓存。加载页减少开局图片迟到，不代表下载体积或运行时绘制成本消失。

小地图虚线标记随机下一圈；HUD显示缩圈序号、开始/完成倒计时及下一圈直径占地图宽度的比例。落地后开始计时，暂停时缩圈计时也暂停。15分钟完成5轮后不再扩圈或重复缩圈。
